# 🎯 بازی حدس عدد (Number Guessing Game)

یک بازی ساده با زبان **Python** و رابط گرافیکی مینیمال با **Tkinter** که برای پروژه درس «مباحث ویژه» ساخته شده است.

## 🎮 نحوه بازی

برنامه یک عدد تصادفی بین **۱ تا ۱۰۰** انتخاب می‌کند. شما **۱۰ فرصت** دارید تا آن را حدس بزنید.

- اگر عدد واردشده بزرگ‌تر از عدد مخفی باشد، برنامه اعلام می‌کند که حدس شما بزرگ‌تر است.
- اگر عدد واردشده کوچک‌تر باشد، برنامه اعلام می‌کند که حدس شما کوچک‌تر است.
- اگر درست حدس بزنید، پیام برد نمایش داده می‌شود.
- اگر فرصت‌ها تمام شود، عدد صحیح نمایش داده می‌شود.
- با دکمه **شروع دوباره** می‌توانید بازی جدیدی آغاز کنید.

## 🛠 زبان، ابزارها و کتابخانه‌ها

- **Python 3** — زبان برنامه‌نویسی پروژه
- **Tkinter** — طراحی رابط گرافیکی (از کتابخانه‌های استاندارد پایتون)
- **random** — تولید عدد تصادفی (از کتابخانه‌های استاندارد پایتون)
- **VS Code** یا **PyCharm** — برای نوشتن و اجرای کد (اختیاری)
- **Git و GitHub** — برای مدیریت نسخه‌ها و انتشار پروژه (اختیاری)

برای این پروژه نیازی به نصب پکیج با `pip` نیست. در بعضی توزیع‌های لینوکس ممکن است لازم باشد Tkinter را جداگانه از بسته‌های سیستم نصب کنید.

## ▶️ روش اجرا

۱. Python 3 را روی سیستم خود نصب کنید.

۲. فایل `guess_game.py` را دانلود یا مخزن را دریافت کنید.

۳. در پوشه پروژه این دستور را اجرا کنید:

```bash
python guess_game.py
```

در برخی سیستم‌ها باید از دستور `python3 guess_game.py` استفاده کنید.
