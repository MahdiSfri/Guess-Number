# 🎯 بازی حدس عدد (Number Guessing Game)

یک بازی ساده با **Python** و رابط گرافیکی مینیمال **Tkinter** برای پروژه درس «مباحث ویژه».

## نحوه بازی

سیستم عددی تصادفی بین ۱ تا ۱۰۰ انتخاب می‌کند. کاربر ۱۰ فرصت دارد آن را حدس بزند. بعد از هر حدس، برنامه می‌گوید عدد واردشده بزرگ‌تر، کوچک‌تر یا درست است. با پایان فرصت‌ها، عدد درست نمایش داده می‌شود. دکمه «شروع دوباره» بازی جدیدی ایجاد می‌کند.

## ابزارها و کتابخانه‌ها

- **Python 3.10+**: زبان برنامه‌نویسی
- **Tkinter**: رابط گرافیکی (ماژول استاندارد پایتون؛ ممکن است در لینوکس به نصب بسته سیستمی Tk نیاز داشته باشد)
- **random**: ساخت عدد تصادفی (کتابخانه استاندارد پایتون)
- **arabic-reshaper**: اتصال درست حروف فارسی
- **python-bidi**: ترتیب راست‌به‌چپ متن فارسی
- **Git / GitHub**: مدیریت و انتشار پروژه

## نصب و اجرا در لینوکس

داخل پوشه پروژه دستورهای زیر را اجرا کنید:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python guess_game.py
```

## مفاهیم استفاده‌شده

تولید عدد تصادفی، شرط‌های `if / elif / else`، توابع، مدیریت ورودی کاربر، رابط گرافیکی Tkinter و نمایش درست متن فارسی.
